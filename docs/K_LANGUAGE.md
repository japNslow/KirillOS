## 1. Философия и архитектура языка

Язык K создавался как встроенный инструмент системного и прикладного программирования, работающий на железе без использования внешних компиляторов и тяжелых runtime-библиотек.

### Ключевые принципы дизайна:
- **Нулевая зависимость от хост-системы:** Исходный код `.k` пишется прямо в терминале KirillOS через текстовый редактор `kano` и мгновенно компилируется в байткод виртуальной машины.
- **Однопроходная трансляция (One-pass Compilation):** Компилятор компилирует программу методом рекурсивного спуска непосредственно в поток байткода виртуальной машины KHEX VM за доли секунды.
- **Прямой аппаратный контроль:** Язык из коробки предоставляет функции работы с текстовой памятью VGA (`0xB8000`), генератором частот PC Speaker на таймере Intel 8254 PIT, аппаратными прерываниями клавиатуры и генератором псевдослучайных чисел.

## 2. Структура программы и точка входа

Программа на языке K состоит из функции точки входа `fn main()`, внутри которой располагаются инструкции, объявления переменных и вызовы функций.

```rust
// Однострочный комментарий начинается с двух слешей
fn main() {
    clear()
    print("Welcome to KirillOS K-Language!\n")
}
```

### Синтаксические правила:
- **Точки с запятой опциональны:** Инструкции разделяются символом переноса строки или фигурными скобками блоков кода `{ ... }`.
- **Комментарии:** Поддерживаются однострочные комментарии вида `// ...`. Всё, что следует за `//` до конца строки, игнорируется компилятором.
- **Чувствительность к регистру:** Имена переменных, ключевые слова и функции чувствительны к регистру (`main` != `Main`).

## 3. Переменные и типы данных

В текущей версии языка K поддерживаются два фундаментальных типа данных:
1. **32-битные знаковые целые числа (`int32_t`):** Диапазон от `-2 147 483 648` до `2 147 483 647`. Числа представляются в десятичном формате.
2. **Строковые литералы:** Последовательность ASCII-символов в двойных кавычках `"..."`. Поддерживаются escape-последовательности:
   - `\n` — перевод строки (ASCII `0x0A`).
   - `\t` — символ табуляции (ASCII `0x09`).

### Объявление переменных (`var`):
Переменные объявляются с помощью ключевого слова `var`:
```rust
var score = 0
var speed = 150
var letter = 65 // ASCII код символа 'A'
```

### Присваивание и повторное использование:
После объявления к переменной можно обращаться напрямую:
```rust
var x = 10
x = x + 5
x = x * 2
```

> [!NOTE]
> Компилятор выделяет под переменные таблицу символов до 32 активных переменных (`var_names[32]`). Переменные имеют глобальную статическую адресацию внутри фрейма виртуальной машины. Имена идентификаторов могут содержать до 15 символов (латинские буквы `a-z`, `A-Z`, цифры `0-9` и символ подчеркивания `_`, при этом имя не может начинаться с цифры).

## 4. Операторы и приоритеты выражений

Парсер выражений языка K строит иерархию вычислений по классической грамматике приоритетов (от низшего к высшему):

| Приоритет | Категория | Операторы | Описание | Ассоциативность |
| :---: | :--- | :---: | :--- | :---: |
| **1 (Низший)** | Сравнение | `==`, `!=`, `<`, `>`, `<=`, `>=` | Проверка равенства, неравенства и отношений порядка. Возвращают `1` (true) или `0` (false). | Слева направо |
| **2** | Аддитивные | `+`, `-` | Сложение и вычитание целых чисел. | Слева направо |
| **3** | Мультипликативные | `*`, `/`, `%` | Умножение, целочисленное деление, остаток от деления (модуло). | Слева направо |
| **4 (Высший)** | Первичные выражения | `( expr )`, числа, переменные, вызовы функций | Группировка скобками, литералы и системные функции-генераторы (`rand()`, `getchar()`, `poll()`). | - |

### Примеры сложных арифметических выражений:
```rust
var result = (10 + 20) * 3 - (100 / 4) % 7
var check = (result >= 50)
```

## 5. Управляющие конструкции: if, while, break

### 5.1 Условный оператор `if`
Выполняет блок кода, если выражение в скобках возвращает ненулевое значение:
```rust
var score = 100
if (score >= 100) {
    color(10, 0)
    print("Victory!\n")
}
```

### 5.2 Цикл `while`
Цикл `while` выполняет вложенный блок кода до тех пор, пока условие истинно:
```rust
var i = 0
while (i < 10) {
    print(i)
    print(" ")
    i = i + 1
}
```

Бесконечный цикл ожидания событий:
```rust
while (1) {
    var key = poll()
    if (key != 0) {
        // обработка нажатия
    }
}
```

### 5.3 Оператор `break`
Оператор `break` прерывает исполнение текущей цепочки команд и завершает выполнение программы (генерирует опкод `OP_EXIT`):
```rust
while (1) {
    var key = getchar()
    if (key == 113) { // ASCII 'q'
        print("Exit requested.\n")
        break
    }
}
```

## 6. Полный справочник встроенных функций

### 6.1 Вывод текста и терминал

#### `print(value)`
Универсальная процедура текстового вывода на экран в текущую позицию курсора.
- **Если аргумент — строковый литерал:** строка заносится в пул данных бинарника и выводится через ядро VGA-драйвера:
  ```rust
  print("Hello, KirillOS!\n")
  ```
- **Если аргумент — выражение или переменная:** вычисляется значение и выводится в терминал в виде знакового десятичного числа:
  ```rust
  var x = -42
  print(x) // Напечатает: -42
  ```

#### `clear()`
Полностью очищает видеопамять VGA текущим фоновым цветом и возвращает курсор в верхний левый угол `(0, 0)`.
```rust
clear()
```

#### `color(fg, bg)`
Устанавливает текущие цвета текста (`fg`) и фона (`bg`) для последующих вызовов `print()`.

**Таблица цветов VGA (0 - 15):**
| Код | Цвет | Код | Цвет |
| :---: | :--- | :---: | :--- |
| `0` | Черный (Black) | `8` | Темно-серый (Dark Grey) |
| `1` | Синий (Blue) | `9` | Светло-синий (Light Blue) |
| `2` | Зеленый (Green) | `10` | Светло-зеленый (Light Green) |
| `3` | Голубой (Cyan) | `11` | Светло-голубой (Light Cyan) |
| `4` | Красный (Red) | `12` | Светло-красный (Light Red) |
| `5` | Пурпурный (Magenta) | `13` | Светло-пурпурный (Light Magenta) |
| `6` | Коричневый (Brown) | `14` | Желтый (Yellow) |
| `7` | Светло-серый (Light Grey) | `15` | Белый (White) |

*Пример:*
```rust
color(14, 1) // Желтый текст на синем фоне
print("Retro Style!\n")
```

#### `cursor(row, col)`
Перемещает аппаратный текстовый курсор VGA в указанную строку и столбец.
- `row` — номер строки (от `0` до `24`).
- `col` — номер столбца (от `0` до `79`).
```rust
cursor(12, 30)
print("Centered Text")
```

---

### 6.2 Прямая VGA-графика

#### `draw(row, col, ch, color)`
Записывает символ `ch` с цветовым атрибутом `color` непосредственно в видеопамять по адресу `0xB8000 + (row * 80 + col) * 2`. Не смещает текстовый курсор и работает с максимальной производительностью без задержек терминального скроллинга.
- `row` — строка (`0` - `24`).
- `col` — столбец (`0` - `79`).
- `ch` — ASCII-код символа (например, `42` для `*`, `35` для `#`).
- `color` — байт атрибута: `(bg << 4) | fg`.
```rust
// Нарисовать символ '@' (ASCII 64) желтым на черном (атрибут 14) в координатах (10, 20)
draw(10, 20, 64, 14)
```

### 6.3 Ввод с клавиатуры

#### `getchar()`
Блокирующая функция чтения символа с клавиатуры. Приостанавливает выполнение программы до тех пор, пока пользователь не нажмет клавишу, и возвращает ее ASCII-код (или скан-код).
```rust
print("Press Enter to continue...\n")
var ch = getchar()
if (ch == 10) { // ASCII Enter
    print("Key pressed!\n")
}
```

#### `poll()` / `pollchar()`
Неблокирующий опрос клавиатурного буфера. Мгновенно возвращает ASCII-код нажатой клавиши либо `0`, если новых нажатий нет. Незаменима для динамических игр и анимаций в реальном времени.
```rust
var key = poll()
if (key == 32) {
    // Нажат пробел
}
```

---

### 6.4 Звук и аппаратный тайминг

#### `beep(freq, ms)`
Генерирует звуковой сигнал заданной частоты через системный динамик (PC Speaker) с использованием таймера PIT (канал 2) на указанное количество миллисекунд.
- `freq` — частота звука в Герцах (например, `440` — нота Ля первой октавы, `523` — До второй октавы).
- `ms` — длительность звучания в миллисекундах.
```rust
beep(440, 150) // Звук 440 Гц длительностью 150 мс
```

#### `delay(ms)`
Приостанавливает выполнение программы на указанное число миллисекунд без загрузки центрального процессора (использует аппаратный таймер прерываний PIT).
```rust
delay(500) // Пауза полсекунды
```

---

### 6.5 Генератор случайных чисел

#### `rand(max)`
Возвращает псевдослучайное целое число в диапазоне от `0` до `max - 1`. Базируется на сверхбыстром 32-битном алгоритме Xorshift.
```rust
var dice = rand(6) + 1 // Бросок кубика: число от 1 до 6
```

### Пример 2: Кликер пробела (Spacebar Clicker)
```rust
// clicker.k - Игра-кликер на скорость
fn main() {
    clear()
    color(11, 0)
    print("=========================================\n")
    print("        SPACEBAR SPEED CLICKER           \n")
    print("=========================================\n")
    print("Instructions:\n")
    print("  - Hit SPACE to increase your score\n")
    print("  - Press 'q' to finish and exit\n\n")

    var score = 0

    while (1) {
        var key = getchar()
        
        // Код клавиши пробел = 32
        if (key == 32) {
            score = score + 1
            color(14, 0)
            print("Score: ")
            print(score)
            print("\n")
            beep(750, 30) // Короткий щелчок
        }

        // Код клавиши 'q' = 113
        if (key == 113) {
            color(12, 0)
            print("\nGame Over! Final Score: ")
            print(score)
            print("\n")
            beep(300, 200)
            break
        }
    }
}
```

### Пример 3: Игра «Угадай число» (Guess The Number)
```rust
// guess.k - Классическая мини-игра с генератором случайных чисел
fn main() {
    clear()
    color(13, 0)
    print("=========================================\n")
    print("       GUESS THE NUMBER (1 - 100)        \n")
    print("=========================================\n")
    color(7, 0)
    print("Thinking of a number between 1 and 100...\n\n")

    var secret = rand(100) + 1
    var attempts = 0

    while (1) {
        color(14, 0)
        print("Enter your guess: ")
        
        // Ввод числа посимвольно
        var guess = 0
        while (1) {
            var c = getchar()
            if (c == 10) { // Enter
                print("\n")
                break
            }
            if (c >= 48) {
                if (c <= 57) {
                    var digit = c - 48
                    guess = guess * 10 + digit
                    print(digit)
                }
            }
        }

        attempts = attempts + 1

        if (guess == secret) {
            color(10, 0)
            print("\n*** BINGO! YOU GUESSED IT! ***\n")
            print("Total attempts: ")
            print(attempts)
            print("\n\n")

            // Победный джингл
            beep(523, 100)
            beep(659, 100)
            beep(784, 150)
            beep(1047, 350)
            break
        }

        if (guess < secret) {
            color(11, 0)
            print("Too low! Try higher.\n\n")
            beep(400, 60)
        }

        if (guess > secret) {
            color(12, 0)
            print("Too high! Try lower.\n\n")
            beep(300, 60)
        }
    }
}
```

### Пример 4: Текстовая анимация и графический демо-скринсейвер
```rust
// bounce.k - Рисование летящего символа через прямую видеопамять VGA
fn main() {
    clear()
    cursor(24, 0)
    color(11, 0)
    print("Bouncing Star Demo. Press any key to stop.")

    var x = 10
    var y = 5
    var dx = 1
    var dy = 1

    var running = 1
    while (running == 1) {
        // Стираем старую позицию (пробел 32, цвет черный 0)
        draw(y, x, 32, 0)

        // Обновляем координаты
        x = x + dx
        y = y + dy

        // Отскок от горизонтальных границ (колонка 0..79)
        if (x >= 79) { dx = -1 }
        if (x <= 0)  { dx = 1 }

        // Отскок от вертикальных границ (строка 0..22)
        if (y >= 22) { dy = -1 }
        if (y <= 0)  { dy = 1 }

        // Рисуем звездочку '*' (код 42) желтым цветом (атрибут 14)
        draw(y, x, 42, 14)

        // Задержка 40 мс (~25 кадров в секунду)
        delay(40)

        // Проверяем нажатие клавиши для выхода
        var k = poll()
        if (k != 0) {
            running = 0
            break
        }
    }

    clear()
}
```
